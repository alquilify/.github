# Alquilify

**Barcelona moves fast. Find your place sooner.**

Alquilify is a Barcelona rental search bot. It watches about 35 agency websites and rental sites, merges duplicate adverts, holds back listings that look like scams, and emails you within minutes when a new flat or room matches your search.
